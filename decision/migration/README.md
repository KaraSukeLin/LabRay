# decision 移轉資料

此目錄只收錄 `decision` 的移轉資訊與重現工具。研究程式及數據已展開於專案內，另一實驗的模型資產、驗證工具與文件不放在此處。

## 索引

- [重現方式](REPRODUCE.md)：以目前路徑執行的校驗、環境與重算命令。
- [目前檔案清單](FILE-MANIFEST.csv)：每個資料或工具檔案的相對路徑、大小與 SHA-256。
- [原研究檔案對照](original-files.csv)：原合併快照內的檔案如何對應到目前專案；研究檔案逐一確認 bytes 相同。
- [原來源清單](source-manifest.csv)：來源路徑與前次精簡方式。它是歷史來源紀錄，完整現行清單以上方 FILE-MANIFEST 為準。
- `SHA256SUMS`：從 `decision/` 執行 `sha256sum -c migration/SHA256SUMS`。
- `metadata/`：此專案的模型小型資產、來源、萃取及驗證收據。
- `tools/`：此專案可獨立使用的工具。

## 路徑調整

原 `README.md` 移至專案根目錄的 `README-original.md`，供歷史追查；新的 README 是目前入口。移轉工具由合併資料包根目錄移到 `migration/tools/`，只調整其找檔根目錄與說明，原研究程式和統計公式不變。

模型資產 index 已按實驗篩選，引用的每個 blob 均隨本專案保留。歷史清單的絕對來源路徑用於識別原資料，並非需要另一個實驗目錄的執行依賴。

不包含大型權重、虛擬環境或前次已省略的大型過程檔案。原合併資料包在 Git 歷史的 commit `6881efa` 中可追溯；目前版本以兩個專案資料夾為入口。
